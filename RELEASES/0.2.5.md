# Nexora 0.2.5

Nexora 0.2.5 is the authoritative synchronization release.

## Implemented runtime behavior

- Added monotonic accepted snapshots separate from raw Udon-synchronized fields.
- Rejects stale snapshots from older authority epochs.
- Rejects revision rollback inside the current authority epoch.
- Tracks duplicate and stale snapshot reception without allowing rejected state to drive playback.
- Restores the last accepted snapshot into synchronized fields before a new owner issues a command, preventing previously rejected raw state from re-entering authority.
- Added synchronized authority epochs and command sequences.
- Added explicit transport command metadata for load, play, pause, stop, seek, volume, loop, playback speed, and authority transfer.
- Added centralized media commands so feature packages no longer need to mutate synchronized media fields directly.
- Bound authority-lease recovery and ownership transfer to media authority epochs.
- Preserves the current reconstructed media time when authority changes.
- Added heartbeat sequence and authority recovery/transfer telemetry.
- Added accepted-snapshot sync status telemetry including authority age, accepted revision/epoch, stale counts, duplicate counts, and rejected-state restoration counts.

## Video synchronization behavior

- `NexoraSnapshotApplier` consumes only accepted authoritative state.
- Volume, loop, and playback-speed revisions no longer force unnecessary play/seek cycles.
- Media changes and load commands reset to the primary backend and perform an actual load.
- Pause, stop, seek, play, and authority-transfer commands reconcile independently.
- Soft drift correction performs a bounded seek only after threshold and cooldown checks.
- Hard drift correction escalates to backend recovery.
- Tracks applied revision, authority epoch, command sequence, measured drift, and correction counts.

## First-party integrations

- Nexora Playlists now routes media loading and stop behavior through the synchronized media command API rather than writing `mediaUrl` directly.
- SpectraOverdrive now consumes accepted authoritative time, playback state, revision, authority epoch, and command metadata rather than raw synchronized fields.
- Streaming is dependency-aligned with Nexora Sync and Video 0.2.5.

## No-stub policy

This release counts only runtime paths that execute real behavior. Package manifests, empty API surfaces, TODO methods, and placeholder integrations do not count as implemented features.

## Platform model

The synchronization model remains backend-independent and is intended to drive the same authoritative timeline across PC/PCVR, Meta Quest, Android, and iOS backends. Unity authoring remains designed for Windows and Linux workflows.

## Certification status

The runtime implementation is committed to `main`. Unity 2022.3.22f1 + VRChat SDK + UdonSharp compile and multi-client runtime qualification are still required before 0.2.5 can be marked compile-certified or production-certified.

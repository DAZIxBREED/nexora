# Nexora 0.2.3

Nexora 0.2.3 is a resiliency and operator-control release.

## Highlights

- Added explicit video backend fault codes for not-ready, load failure, playback failure, stalls, unsupported media, missing platform backends, and exhausted recovery.
- Added backend fault counters, recovery counters, fault messages, and active-backend validation.
- Made the streaming watchdog react to backend faults as well as time stalls.
- Added recovery-exhaustion reporting so operators can distinguish transient stalls from a backend that has stopped recovering.
- Added playlist failed-item tracking and optional automatic skip-to-next behavior.
- Preserved queued-item priority when recovering from a failed playlist item.
- Added permission audit telemetry for denied control and administration attempts plus synchronized last policy actor identity.
- Expanded diagnostics with info/warning/error severity, counters, timestamps, newest-message access, and clear/reset support.

Packages not changed by this release retain their independent versions.

## Platform intent

The backend fault and recovery model remains platform-neutral and supports Nexora's PC/PCVR, Meta Quest, Android, and iOS backend-routing architecture. Unity authoring continues to target Windows and Linux development workflows.

## Validation status

Repository changes are committed to main. Unity 2022.3.22f1 + VRChat SDK + UdonSharp compile/runtime certification remains required before calling this release production-certified.

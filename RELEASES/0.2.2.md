# Nexora 0.2.2

Nexora 0.2.2 is a cross-platform reliability release for PCVR, Meta Quest, Android, and iOS.

## Highlights

- Added `NexoraBackendContractGuard` to validate that the correct platform-specific video backend is present before runtime use.
- Added `NexoraSnapshotApplier` in the video package to consume authoritative synchronized state without creating a circular package dependency.
- Added periodic playback drift correction using backend-reported media time.
- Escalates large drift from seek correction to backend recovery.
- Hardened `NexoraMediaState` with source-player metadata, late-join serialization replay, ownership-transfer notification, synchronized volume, loop, and playback-rate updates.
- Added `NexoraStreamWatchdog` for stall detection and bounded automatic recovery.
- Kept platform routing distinct for PC/PCVR, Android/Quest, and iOS while preserving one synchronization model.
- Aligned Sync, Video, Streaming, Playlists, and Spectra package dependency versions to 0.2.2.

## Platform intent

The same Nexora synchronization, permissions, playlist, automation, and integration state is shared across PCVR, Quest, Android, and iOS. Video backends remain platform-selectable so mobile-specific playback behavior can evolve without forking the orchestration layer.

## Validation status

Source and package dependency structure have been reviewed in-repository. Unity 2022.3.22f1 + VRChat SDK + UdonSharp compile/runtime validation is still required before calling this release compile-certified.

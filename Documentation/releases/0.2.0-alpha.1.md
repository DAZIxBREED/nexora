# Nexora 0.2.0-alpha.1

This release advances Nexora from the initial package skeleton into a harder, more reliable synchronized runtime.

## Highlights

- Hardened administrative permissions so ordinary unlocked guests cannot change the global lock state.
- Added explicit local role and administrator checks for Owner, Master, Moderator, DJ, Trusted, and Guest roles.
- Expanded synchronized playlists with previous/next navigation, repeat-current, repeat-playlist, current-title access, and playlist revisions.
- Added a synchronized authority lease with server-time heartbeat, owner tracking, authority epochs, stale-lease recovery, and master failover when the authority leaves.
- Added synchronization health evaluation with warning/critical drift thresholds and stale-authority detection.
- Preserved the single-authoritative-time model used by video backends, streaming, and SpectraOverdrive.

## Package versions

- `com.nexora.sync` -> `0.2.0-alpha.1`
- `com.nexora.permissions` -> `0.2.0-alpha.1`
- `com.nexora.playlists` -> `0.2.0-alpha.1`

Other Nexora packages remain independently versioned until their public/runtime surfaces change.

## Platform targets

The architecture remains targeted at PC/PCVR, Meta Quest, Android, and iOS runtime participation, with Unity project authoring and package maintenance designed for both Windows and Linux development hosts.

## Validation status

The code is committed to `main`, but this alpha still requires compile and runtime validation in the target Unity 2022.3.22f1 + VRChat SDK + UdonSharp environment before it should be considered release-certified.
